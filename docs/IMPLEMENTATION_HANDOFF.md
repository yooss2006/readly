# Readly 초기 MVP 구현 핸드오프

이 문서는 새 세션에서 Readly의 초기 MVP와 의미 있는 테스트를 한 번에 구현하기 위한 출발점이다. 제품 결정은 [ADR.md](./ADR.md), 기술 결정은 [TECHNICAL_DECISIONS.md](./TECHNICAL_DECISIONS.md)를 기준으로 한다. 이 문서의 `확인 필요 사항`은 확정 요구사항이 아니다.

## 구현 목표

- 초대한 사용자만 이용할 수 있는 URL 글 요약 웹 서비스를 구현한다.
- 사용자는 요약만 생성하거나 요약과 음성을 함께 생성할 수 있다.
- 같은 URL의 저장된 결과를 재사용하고, 기존 요약에 음성만 추가할 수 있다.
- 계정별 일일 생성 제한과 서비스 전체 월 비용 제한을 적용한다.
- 실제 동작과 중요한 경계 조건을 검증하는 테스트를 포함한다.

## 확정된 범위

- 대상은 로그인 없이 열리는 정보성 글이다.
- 사용자는 Google 계정으로 로그인하며, 허용된 이메일만 접근한다.
- 새 요약 생성, 요약과 음성 동시 생성, 기존 요약에 음성 추가는 계정별 하루 최대 5회 중 각각 1회로 센다. 저장된 결과 조회는 횟수에 포함하지 않는다.
- 같은 URL의 요약과 음성은 사용자들이 함께 이용한다. 기존 요약이 있으면 그대로 반환한다.
- 새 요청에 따른 본문 추출·요약·음성 생성 비용의 월 상한은 3만 원이다. 앱은 예상 비용 2만 4천 원에 도달하면 새 생성을 멈추고, 저장된 결과 조회는 허용한다.
- 본문 추출은 Firecrawl 무료 구간에서 시작한다. 무료 사용량이 소진되면 새 본문 추출을 중단한다.

## 확정된 기술 방향

- Next.js와 TypeScript로 웹 화면과 서버 처리를 한 프로젝트에 구현한다.
- 인증, 요약 데이터, 음성 파일 보관은 Supabase Free를 사용한다.
- 웹 앱 배포 대상은 Vercel Hobby다.
- 요약과 음성 생성은 OpenAI를 사용한다. 구체적인 모델은 아직 정하지 않았다.
- OpenAI 전용 프로젝트에 강제 월 지출 상한과 사전 알림을 설정한다.

## 비밀값과 버전 관리

- 로컬 API 키와 다른 비밀값은 `.env`에서 관리한다. `.env`는 Git에 추적되지 않아야 한다.
- 구현 시 `.gitignore`에 `.env`와 그 변형 파일을 포함하고, 값이 없는 `.env.example`을 제공한다.
- 비밀값은 브라우저 코드, 로그, 테스트 출력에 노출하지 않는다. 배포 환경의 비밀값은 배포 서비스의 환경 변수로 설정한다.
- 현재 작업 공간에는 `docs/`의 문서만 있고, `.git`, `.gitignore`, `.env` 파일은 없다. 새 세션에서 실제 상태를 다시 확인한다.

## 테스트 완료 기준

- 테스트는 로그인 접근 제한, 동일 URL 재사용, 요약만 생성, 요약과 음성 생성, 기존 요약에 음성 추가, 일일 제한, 월 비용 제한, 외부 서비스 실패를 검증한다.
- 테스트를 통과시키기 위해 구현과 같은 답만 돌려주는 무의미한 Mock 테스트를 만들지 않는다. 순수 규칙은 실제 입력과 기대 결과로 검증하고, 저장·인증 연동은 가능한 범위에서 실제 테스트 환경으로 검증한다.
- API 키와 테스트 계정이 준비되어 있으면 Firecrawl과 OpenAI의 실제 호출을 확인하는 스모크 테스트를 실행한다. 준비되지 않았다면 어떤 검증을 실행하지 못했는지 명시한다.
- `.env`가 Git 추적 대상에서 제외되는지 확인한다.

## 확인 필요 사항

- 요약과 음성의 언어 정책
- 요약본의 기본 형태와 길이
- 첫 MVP에서 PDF URL 지원 여부
- 생성 실패 시 일일 횟수 차감과 부분 성공 처리
- 실제 추출·요약 품질을 확인할 대표 URL
